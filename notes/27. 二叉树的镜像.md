## 解题思路

```java
public TreeNode flipTree(TreeNode root) {
    if (root == null)
        return root;
    swap(root);
    flipTree(root.left);
    flipTree(root.right);
    return root;
}

private void swap(TreeNode root) {
    TreeNode t = root.left;
    root.left = root.right;
    root.right = t;
}
```
