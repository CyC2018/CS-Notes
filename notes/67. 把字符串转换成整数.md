# 67. 把字符串转换成整数

## 题目链接

[Leetcode](https://leetcode.cn/problems/ba-zi-fu-chuan-zhuan-huan-cheng-zheng-shu-lcof/)

## 题目描述

实现 atoi，将一个字符串转换成一个整数，要求不能使用字符串转换整数的库函数：跳过开头的空格，读入可选的正负号，再读入尽可能多的数字，遇到非数字字符就停止；没有读到数字时返回 0，超出 int 范围时返回 Integer.MAX_VALUE 或 Integer.MIN_VALUE。牛客的版本要求整个字符串都是合法数值，否则返回 0。

```text
Input:
"   -42"
"4193 with words"
"words and 987"
"-91283472332"

Output:
-42
4193
0
-2147483648
```

## 解题思路

按上面的规则逐个字符处理，难点在于判断溢出。溢出要在乘 10 之前判断：border = Integer.MAX_VALUE / 10 = 214748364，ret 大于 border，或者等于 border 且下一位大于 7 时，ret × 10 加上下一位会超过 2147483647，直接返回边界值。负数的下界 -2147483648 末位是 8，也走这个分支，返回 Integer.MIN_VALUE，结果正确。

```java
public int myAtoi(String str) {
    if (str == null || str.length() == 0)
        return 0;
    int i = 0, n = str.length();
    while (i < n && str.charAt(i) == ' ') {
        i++;
    }
    if (i == n)
        return 0;
    int sign = 1;
    char c = str.charAt(i);
    if (c == '+' || c == '-') {
        sign = c == '-' ? -1 : 1;
        i++;
    }
    int ret = 0;
    int border = Integer.MAX_VALUE / 10;
    while (i < n) {
        c = str.charAt(i);
        if (c < '0' || c > '9')
            break;
        if (ret > border || (ret == border && c > '7')) {
            return sign == 1 ? Integer.MAX_VALUE : Integer.MIN_VALUE;
        }
        ret = ret * 10 + (c - '0');
        i++;
    }
    return sign * ret;
}
```
