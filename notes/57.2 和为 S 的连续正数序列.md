# 57.2 和为 S 的连续正数序列

## 题目链接

[Leetcode](https://leetcode.cn/problems/he-wei-sde-lian-xu-zheng-shu-xu-lie-lcof/)

## 题目描述

输出所有和为 S 的连续正数序列。例如和为 100 的连续序列有：

```text
[9, 10, 11, 12, 13, 14, 15, 16]
[18, 19, 20, 21, 22]。
```

## 解题思路

```java
public int[][] fileCombination(int target) {
    List<int[]> ret = new ArrayList<>();
    int start = 1, end = 2;
    int curSum = 3;
    while (end < target) {
        if (curSum > target) {
            curSum -= start;
            start++;
        } else if (curSum < target) {
            end++;
            curSum += end;
        } else {
            int[] arr = new int[end - start + 1];
            for (int i = start; i <= end; i++) {
                arr[i - start] = i;
            }
            ret.add(arr);
            curSum -= start;
            start++;
            end++;
            curSum += end;
        }
    }
    return ret.toArray(new int[ret.size()][]);
}
```
