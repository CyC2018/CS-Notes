# 22. 链表中倒数第 K 个结点

[Leetcode](https://leetcode.cn/problems/lian-biao-zhong-dao-shu-di-kge-jie-dian-lcof/)

## 解题思路

设链表的长度为 N。设置两个指针 P1 和 P2，先让 P1 移动 K 个节点，则还有 N - K 个节点可以移动。此时让 P1 和 P2 同时移动，可以知道当 P1 移动到链表结尾的 null 时，P2 移动了 N - K 个节点，到达第 N - K + 1 个节点，该位置就是倒数第 K 个节点。

```java
public ListNode trainingPlan(ListNode head, int cnt) {
    if (head == null)
        return null;
    ListNode p1 = head;
    while (p1 != null && cnt-- > 0)
        p1 = p1.next;
    if (cnt > 0)
        return null;
    ListNode p2 = head;
    while (p1 != null) {
        p1 = p1.next;
        p2 = p2.next;
    }
    return p2;
}
```
