# 10.3 跳台阶

## 题目链接

[Leetcode](https://leetcode.cn/problems/qing-wa-tiao-tai-jie-wen-ti-lcof/)

## 题目描述

一只青蛙一次可以跳上 1 级台阶，也可以跳上 2 级。求该青蛙跳上一个 n 级的台阶总共有多少种跳法。

跳 n 阶台阶，可以先跳 1 阶台阶，再跳 n-1 阶台阶；或者先跳 2 阶台阶，再跳 n-2 阶台阶。而 n-1 和 n-2 阶台阶的跳法可以看成子问题，该问题的递推公式为：

<div align="center"> <img src="https://cs-notes-1256109796.cos.ap-guangzhou.myqcloud.com/508c6e52-9f93-44ed-b6b9-e69050e14807.jpg" width="350px"> </div><br>

```java
public int trainWays(int num) {
    if (num <= 1)
        return 1;
    int pre2 = 1, pre1 = 1;
    int result = 0;
    for (int i = 2; i <= num; i++) {
        result = (pre2 + pre1) % 1000000007;
        pre2 = pre1;
        pre1 = result;
    }
    return result;
}
```
